The Problem that started it all (1600s)

Average Speed — Easy ✓
A car travels 120 km in 2 hours.
Average speed = 120 ÷ 2 = 60 km/h.

You need two points in time. Straightforward.
Instantaneous Speed — Impossible? ✗
What is the car's speed at exactly 1:00:00 PM?
One exact moment → time interval = 0.

Speed = distance ÷ 0. You cannot divide by zero!
Newton's Breakthrough Idea
Take two points VERY close together on a curve. Find the average rate (slope of the chord). Now make them even closer. Closer still. The value this average rate approaches — but never actually reaches — as the gap h → 0 is the derivative.

f'(x) = limh→0 [ f(x+h) − f(x) ] / h

Newton vs Leibniz — The Famous Rivalry

Isaac Newton (England, ~1666)
Invented calculus to explain gravity and planetary orbits. Called it "Method of Fluxions". Used dots over variables (ẋ).

Didn't publish immediately. Very secretive.
Gottfried Leibniz (Germany, ~1675)
Invented it independently for curves and geometry. Published first in 1684. Invented the notation dy/dx and ∫.

This notation is what you write in your exam today.
Verdict: Both invented it independently. Both deserve credit. Their famous dispute divided European mathematicians for decades. Today we use Leibniz's notation (dy/dx) but Newton's physics applications.

    Special Techniques

    Inverse Function
    Use when asked for dx/dy but you have dy/dx
    dx/dy = 1 / (dy/dx), dy/dx ≠ 0
    • Find dy/dx normally
    • Flip it to get dx/dy
    • Indian example: y = demand equation, find rate of demand change w.r.t. price
    Log Differentiation
    Use when variable x is in the exponent
    If y = [f(x)]g(x) → take ln both sides
    • Take ln both sides: ln y = g(x) · ln[f(x)]
    • Differentiate: (1/y)(dy/dx) = RHS
    • Multiply both sides by y
    • Key identity: d/dx[ln y] = (1/y)·(dy/dx)
    Implicit Differentiation
    Use when y cannot be isolated
    d/dx[yn] = n·yn-1·(dy/dx)
    • Differentiate both sides w.r.t. x
    • Apply chain rule wherever y appears
    • Collect dy/dx terms on one side
    • Solve for dy/dx
    Parametric
    Use when both x and y are in terms of t
    dy/dx = (dy/dt) ÷ (dx/dt), dx/dt ≠ 0
    • Find dy/dt by differentiating y w.r.t. t
    • Find dx/dt by differentiating x w.r.t. t
    • Divide them
    Second Order
    Rate of the rate — differentiate dy/dx once more
    d2y/dx2 = d/dx ( dy/dx )
    • Find dy/dx first (first derivative)
    • Differentiate dy/dx again
    • Physical meaning: if y = position → dy/dx = velocity → d²y/dx² = acceleration
    Which Method? — Decision Guide
    Function inside function? → Chain Rule
    x is in the power? → Log Diff
    Can't isolate y? → Implicit
    x,y both in terms of t? → Parametric
    Need dx/dy? → Flip dy/dx

    Key Formulas
    Tangent at (x₀, y₀): y − y₀ = f'(x₀) · (x − x₀)
