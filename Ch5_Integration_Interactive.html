Two Problems That Forced Mathematicians to Invent Integration

Problem 1 — Irregular Area
A farmer's field is bounded by a river — a curved boundary. How to find the area?

You can't use length × width. The edge is curved, not straight. There is no simple formula.
Problem 2 — Total from Rate
You know the speed at every instant. How far did you travel in total?

You need to "add up" infinitely many tiny (speed × time) slices. This is integration.
Newton's & Leibniz's Solution — The Integral
Slice the area into n thin vertical strips of width Δx. Each strip has area ≈ f(x) × Δx. Sum all strips → this is Σ f(xᵢ) Δx. As Δx → 0 (strips get infinitely thin), the sum becomes EXACT. This limit is the definite integral:

∫ab f(x) dx = limn→∞ Σ f(xᵢ) Δx

Integration = Reverse of Differentiation

Differentiation (Ch. 3)
f(x) = x³
f'(x) = 3x²
slope at each point
Integration (Ch. 5) — REVERSE
f(x) = 3x²
∫3x² dx = x³ + c
area / total accumulated
Key identity: If d/dx[F(x)] = f(x), then ∫f(x) dx = F(x) + c.
The "+ c" is the constant of integration — because differentiating any constant gives 0, so we can't know what constant was there. Always write "+ c" for indefinite integrals!
