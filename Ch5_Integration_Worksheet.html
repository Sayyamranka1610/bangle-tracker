Always add + c for indefinite integrals. The constant of integration exists because differentiating any constant gives 0, so we cannot determine it without a condition (initial value).

Part B — Three Main Methods

1. Integration by Substitution

If integrand = f(g(x)) · g'(x), let u = g(x), du = g'(x) dx. Gives ∫f(u) du.
Steps: (i) Choose u = inner function   (ii) Find du   (iii) Replace x-terms with u-terms   (iv) Integrate in u   (v) Back-substitute

2. Integration by Parts

∫u · dv = u·v − ∫v · du    (ILATE rule for choosing u)
ILATE order: Inverse trig → Logarithm → Algebraic → Trigonometric → Exponential. The function that appears earliest = u. The remaining part = dv.

3. Definite Integrals (Newton-Leibniz Formula)

∫ₐᵇ f(x) dx = F(b) − F(a) where F'(x) = f(x)
Find the antiderivative F(x), substitute upper limit, substitute lower limit, subtract. The constant c always cancels.

Substitution Example — ∫ 2x(x²+1)⁵ dx
Find: ∫ 2x(x²+1)⁵ dx
1
Let u = x²+1
Inner function inside the power
2
du = 2x dx
The 2x in the integrand matches exactly — perfect substitution
3
∫2x(x²+1)⁵ dx = ∫u⁵ du
Replace 2x dx = du and x²+1 = u
4
= u⁶/6 + c
∫u⁵ du = u⁶/6 (power rule)
5
= (x²+1)⁶/6 + c
Back-substitute u = x²+1
Answer: (x²+1)⁶/6 + c
By Parts Example — ∫ x · eˣ dx
Find: ∫ x · eˣ dx
1
u = x (A), dv = eˣ dx (E)
ILATE: Algebraic before Exponential → u = x
2
du = dx, v = eˣ
Differentiate u, integrate dv
3
∫x·eˣ dx = x·eˣ − ∫eˣ dx
Formula: ∫u dv = uv − ∫v du
4
= x·eˣ − eˣ + c = eˣ(x−1) + c
∫eˣ dx = eˣ. Factorising: take eˣ common.
Answer: eˣ(x − 1) + c
Definite Integral Example — ∫₀² (3x²+2) dx
Evaluate: ∫₀² (3x²+2) dx
1
∫(3x²+2) dx = x³ + 2x
Antiderivative (c cancels in definite integrals)
2
F(2) = 2³ + 2(2) = 8 + 4 = 12
Upper limit: x = 2
3
F(0) = 0³ + 2(0) = 0
Lower limit: x = 0
4
F(2) − F(0) = 12 − 0 = 12
Upper minus lower
Answer: 12
